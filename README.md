# Truckopplæring – nivåer

Interaktivt skjema for VG2 Transport og logistikk, Haugaland videregående skole.

Elevene vurderer seg selv på 27 punkter fordelt på tre nivåer (Nybegynner, Trygg, Ekspert). De legger ved bilder og video som dokumentasjon, og lager deretter én innleveringsfil som leveres i itslearning/Teams.

- Alt lagres lokalt i elevens nettleser – ingen data sendes til GitHub eller andre servere.
- Innleveringsfilen er en selvstendig HTML-fil med tekst, bilder og video.

## Publisering
Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.
